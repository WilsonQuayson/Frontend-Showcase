# Frontend Mentor Challenges

This repository contains my solutions to various Frontend Mentor challenges. Each project is built as a separate mini-app inside this single repository, focusing on real-world UI implementation, responsive design, and modern frontend development practices.

## Purpose

The goal of this repo is to improve and demonstrate skills in:

- React (component architecture, hooks, routing)
- TypeScript (where applicable)
- Tailwind CSS
- Responsive design (mobile-first approach)
- Accessibility best practices
- Translating UI designs into working applications

## Tech Stack

Most projects use:

- React
- Vite
- Tailwind CSS
- TypeScript (some projects)
- React Router (when needed)

## Project Structure

Each challenge lives in its own folder:

frontend-mentor-challenges/
├── challenge-1/
│   ├── src/
│   ├── public/
│   └── README.md
├── challenge-2/
│   ├── src/
│   ├── public/
│   └── README.md
└── ...

Each folder is a standalone project that can be run independently.

## Running a Project

To run any challenge:

cd challenge-name

npm install

npm run dev

Then open:

http://localhost:5173

## What I Focus On

While building these projects, I aim to go beyond just matching the design:

- Clean and reusable component structure
- Accurate implementation of layouts and spacing
- Responsive behavior across devices
- Semantic HTML and accessibility considerations
- Maintainable and scalable code structure
